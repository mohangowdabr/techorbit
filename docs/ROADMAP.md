# TechOrbit Complete Project Roadmap

## 1. Product Vision
TechOrbit connects the complete participant journey:
**Discover -> Evaluate -> Apply -> Connect -> Participate -> Submit -> Showcase -> Grow.**

## 2. Release Milestones
- **Release 0: Technical Foundation**: Next.js App Router, TypeScript, Tailwind styling, Supabase DB + RLS, and responsive token system.
- **Release 1: Opportunity Discovery (Opportunity Radar)**: Multi-category filters, full-text search, verified opportunity badges, official links, save/track interactions.
- **Release 2: Real-time Ingestion & Moderation**: Adapters, provenance tracking, admin verification, and data health metrics.
- **Release 3: Participant Dashboard**: 9 application stages, deadline calendars, reminder preferences, self-reported vs organizer-confirmed indicators.
- **Release 4: Organizer Portal**: Event creator wizard, submission review, live announcements, and attendee analytics.
- **Release 5: TeamMatch & Community**: Teammate cards, collaboration requests, and hackathon team formation.
- **Release 6: Developer Passport**: Public portfolio, verified badges, GitHub projects, and verifiable achievements.
- **Release 7: TechOrbit Live & Judging**: Direct online hackathon execution, submission portals, judging scorecards, and live results.
- **Release 8: TechOrbit Intelligence**: Matchmaker recommendation engine, eligibility checklist, and natural-language search copilot.
- **Release 9: Security, Verification & Public Launch**: Automated tests, end-to-end security policies, and production deployment guide.
